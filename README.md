Trinetra Omni – Project Overview
🌟 Introduction

Trinetra Omni is an AI-powered, scalable marketplace platform designed to connect sellers (farmers, vendors, businesses) with consumers through a microservices-based architecture.

Inspired by the concept of Shiva’s Trinetra (three eyes), the platform focuses on:

👁️ Vision → Market insights & analytics

🤖 Intelligence → AI-driven pricing & recommendations

✅ Trust → Transparency (fair pricing & product verification)

👉 “Omni” represents all-in-one, always-available support across domains.

🎯 Objective

To build a unified platform that:

Enables sellers to list and manage products

Helps consumers get fair prices & trusted products

Uses AI to provide smart pricing and demand insights

Prevents price manipulation (especially for travelers)

Supports multi-category expansion (fruits, groceries, food, ornaments, etc.)

🏗️ System Architecture

Built using Microservices Architecture:

Core Services:

API Gateway → Entry point for all requests

Config Server → Centralized configuration

Service Registry → Service discovery

Auth Service → JWT-based authentication

Business Services:

Seller Service → Manages sellers

Catalog Service → Product management

Order Service → Handles order lifecycle

Inventory Service → Stock management

Payment Service → Transaction handling

Notification Service → Alerts & updates

Intelligence Services:

Intelligence Service → AI pricing & analytics

Trust Service → Verification & certification

🔄 Workflow (Simplified)

Seller lists product

AI suggests optimal price

Consumer places order

Order service validates inventory

Payment processed

Notification sent

Trust & analytics updated
